# Hotel Booking Cancellation Prediction

Machine learning project comparing Logistic Regression and Random Forest to predict hotel booking cancellations.

Includes EDA, feature engineering, model evaluation, external holiday API integration, and a Streamlit app.

Dataset: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

## Run the app
pip install -r requirements.txt
streamlit run app.py


## Dataset

Datasetet kommer från Kaggle:
https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand

För att köra notebooken från början, ladda ner
`hotel_bookings.csv` och placera filen i projektmappen.

## Installation

Installera appens beroenden:

`pip install -r requirements.txt`

För att köra notebooken behövs även matplotlib,
seaborn, scipy och requests.

## Starta appen lokalt

`streamlit run app.py`
